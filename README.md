# 📏 Euclidean vs Manhattan Distance — Interactive Streamlit App

An interactive **Streamlit web application** that visually explains and compares  
**Euclidean Distance (L2 norm)** and **Manhattan Distance (L1 norm)** — two fundamental
distance metrics widely used in Machine Learning.

This project is designed for **beginners**, students, and anyone learning
distance-based algorithms such as **KNN**, **K-Means**, and clustering methods.

## 🧠 Concepts Covered

### 📐 Euclidean Distance (L2 Norm)
- Straight-line distance between two points
- Common in clustering, embeddings, and regression models

### 🧭 Manhattan Distance (L1 Norm)
- Grid-based distance using horizontal + vertical movement
- Useful in high-dimensional feature spaces

### 📊 Visual Learning
- Geometric intuition through plots
- Distance path comparison
- Distance field heatmaps


---

## ✨ Features

- Interactive selection of two 2D points
- Real-time distance calculation
- Visual comparison of Euclidean vs Manhattan paths
- Heatmap visualization for both distance metrics
- Clean and beginner-friendly UI using Streamlit
